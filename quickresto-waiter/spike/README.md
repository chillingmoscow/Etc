# Фаза 0 — спайк проверки QuickResto API

Этот скрипт проверяет, что задумку **в принципе можно реализовать** на вашем аккаунте,
ДО разработки приложения. Это самый важный шаг плана.

## Безопасность (обязательно)

- **Не вставляйте логин/пароль в код, скрипты или чаты.** Только через переменные окружения.
- Запускайте **на своей машине**, вне часов работы (или в тренировочной смене на iPad).
- **Сначала чтение, запись — в последнюю очередь.** Логируйте id всех тестовых заказов.
- По возможности заведите **отдельного API-пользователя** с минимальной ролью.

## Запуск

Нужен Node.js 18+.

```bash
# Только чтение: A (авторизация) + B (меню) + C (поиск модуля столов)
QR_LAYER=ваш_поддомен QR_LOGIN=логин QR_PASSWORD=пароль node spike.mjs

# + D: создать тестовый заказ из одной позиции (id блюда возьмите из вывода B)
QR_LAYER=... QR_LOGIN=... QR_PASSWORD=... node spike.mjs --create --dish=<dishId>

# + E (ГЛАВНЫЙ ТЕСТ): заказ с привязкой к столу (id стола — из вывода C)
QR_LAYER=... QR_LOGIN=... QR_PASSWORD=... node spike.mjs --create --dish=<dishId> --table=<tableId>

# F: отмена тестового заказа (или погасите на iPad)
QR_LAYER=... QR_LOGIN=... QR_PASSWORD=... node spike.mjs --cancel=<orderId>
```

## Что проверяем (чек-лист)

- **A** — авторизация Basic Auth работает, API доступен на тарифе.
- **B** — читается меню (`/tree`), видны id блюд, цены, модификаторы.
- **C** — находится модуль/класс столов и залов (перебор гипотез; иначе — вопрос поддержке).
- **D** — `POST /create` реально создаёт заказ, возвращает `id` и `status`.
- **E (решающий)** — заказ с привязкой к столу появляется **на нужном столе** на iPad,
  уходит на кухню, допускает дозаказ, закрывается/оплачивается на терминале.
- **F** — найден способ отменить/погасить тестовый заказ.

## Итог спайка

Запишите: точную схему ответа `/create`, какое поле дало привязку к столу,
рабочий способ отмены, и **вердикт GREEN / YELLOW / RED** (см. основной план, раздел «Фаза 0»).
По этим данным правится один файл бэкенда — `bff/quickResto.mjs` (функция `buildOrderPayload`)
и переменные в `bff/.env`.
